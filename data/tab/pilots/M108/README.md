## 6. 软件与设备使用边界

- 现有 MAC 已有只读 `/api/tab/week12?room=M108&date=2026-11-02`（日期可换成 11/03–11/06），会从重建大 JSON 按教室返回记录。**本次仅提交 M108 独立审核数据，不修改该端点、不自动部署、不改变运行时的课程结果。**
- 上述现有端点是**公开只读**的；单独存储在私有 GitHub 仓库、不放在 `public/` **不能**保证这部分课表对外不可见。若要将学校教务数据限制为校内/设备可见，必须先经过学校授权并补充后端访问控制。
- 向真实 Tab 发送画面前，需把这份文件经过正式 `SchoolScheduleAdapter` 转为显示合同；不能因 `no_record_in_room_export` 直接显示“教室空闲”。
- 本源文件不证明教师出勤、临时调课、现场人数、设备联机、续航或其他学周重复。
- M108 的选定是**试点范围确定**，不是已经获得安装许可或完成现场部署；P4 仍需要安装位置、Wi-Fi、电源、设施许可、权限和实际画面对账。
