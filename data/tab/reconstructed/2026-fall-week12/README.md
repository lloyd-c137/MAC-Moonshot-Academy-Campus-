已将经用户确认有效的第12周教室课表，与全校课程 Block CSV、脱敏学生课表和学校统一 Block 规则交叉验证，完成 A–I 九组共 42 个周时间模板时段。

- 从全校 CSV 展开的课节：**573** 条（其中4条没有教室编号，不能绑定 Tab）。
- 同室同 Block 展示合并：M125 E Block 的5个课节由两条课程记录合为同一显示条目；最终分配展示条目 **564**。
- 加入非重复的现场/个人观察活动共 **46** 条后，总计 **610** 条可用于第12周的**待校验展示记录**。
- 全校课程 CSV 涉及 **22** 个编号教室；合并样本活动后触及 **23** 个编号教室（额外包含 M104）。
- **仍有 10 门少课时课程没有证据确认实际选用哪些子时段**；另有1条 S2 课程缺少上课地点。
- 原始数据不含教师/学生名单的发布副本；按用户要求对 M125 重合课程**合并展示但保留两条来源**。

## 严格的真实性边界

1. 学校已被用户确认使用统一的 A–I Block 时间规则，**不必逐教室单独安排 Block 时间**。
2. **不能**用 4、3、2 课时课程自动占满该 Block 的所有时段。已经由某一班级记录观察到的短课时排列，可作为其他同 Block、同周课时课程的**推断模式**，不能替代最终校验。
3. 课程表原始字段 `Semester-Long` 没写 S1/S2 的，不能把每门课程都默认当成整个 Fall 学期有效。
4. M125 E Block 两门课程按用户要求合并成同一个教室显示时段，**不意味着两门课都在该时刻同时实际教学**；仍需核对学期安排。
5. 学生课表和三间教室教务导出可能包含课外活动；当前仅对已观察到的教室补充，不能当作全校课外活动清单。
6. 本资料不含动态调课、临时停课、考试周/特殊日全部例外，以及真实有人与否的传感器数据。
7. 真实教务数据保持私有：**不要未经校方授权直接复制到 `public/`、静态客户端包或匿名设备 API**。
