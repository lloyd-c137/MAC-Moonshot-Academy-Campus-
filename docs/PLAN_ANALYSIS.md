### 3. 数据来源与真实性准则 (Truth Discipline)
1. **单层平面图原则**：本系统严格基于单一权威图纸 FF-01 构建，绝不脑补或虚构不存在的多楼层；在 UI 楼层选择器中明确将其他楼层标为 **Not Available (无图纸依据)**。
2. **状态与属性分离**：
   - `Access`: Open, Closed, Restricted, Unknown
   - `Occupancy`: Available, In Use, Crowded, Unknown
3. **隐私空间保护**：护士站、心理咨询中心、隔离室、高管办公室不公开精细实时人流数据。
4. **演示模式标识**：界面清晰标明当前环境读数与占用属于校准 Demo 数据模型，已预备传感器接入标准协议。
